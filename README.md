# NovelVerse AI

Nền tảng hỗ trợ dịch thuật, biên tập và đọc tiểu thuyết đa ngôn ngữ tích hợp trí tuệ nhân tạo.

## Thông tin đồ án

- Sinh viên: Nguyễn Viết Lãm
- MSSV: 2380601183
- Lớp: 23DTHC6

## Mô tả

Hệ thống hỗ trợ dịch tiểu thuyết (Trung/Anh -> Việt) bằng AI (Gemini API), quản lý thư viện truyện/chương, quản lý thuật ngữ/nhân vật để đảm bảo nhất quán bản dịch, trình biên tập song ngữ, kiểm tra chất lượng bản dịch, và website đọc truyện công khai.

## Các module chính

1. Xác thực và quản lý người dùng
2. Quản lý thư viện truyện và chương
3. Dịch nội dung bằng trí tuệ nhân tạo (Gemini API)
4. Quản lý nhân vật và thuật ngữ
5. Trình biên tập song ngữ
6. Kiểm tra chất lượng bản dịch
7. Website đọc truyện
8. Dashboard và thống kê
9. Xử lý lỗi, bảo mật và quyền nội dung
